# Doorstep Mart

A modern Flutter e-commerce application that delivers fresh groceries and daily essentials directly to your doorstep. Built using Firebase, Provider, and  Flutter architecture.

---

##  Features

- Firebase Authentication (Login / Signup)
- Firebase Firestore (Product Data, Cart, Orders...)
- Firebase App Check for app security
- State Management using `provider`
- Dynamic Product Grid with Firestore Images
- Cart and Favorites Management
- Real-time Notifications Count
- PageView + BottomNavigationBar Navigation
